# SPEC-v3 — design-d 최종 수정 (src/design-d.html 를 제자리에서 고친다)

이전 사양(SPEC.md §4–§7, SPEC-v2.md 전부)은 그대로 유효하다. 아래는 **추가·변경**만. 하나도 빠뜨리지 말 것.

## 1. 괄호 표기: 【 】 → [ ]
- 전문(fullText) 블록 제목과 한 줄 머리 블록의 `【주 문】`, `【이 유】`, `【전문】`, `【피 고 인】` … 을 **모두 `[주 문]`, `[이 유]`, `[전문]`, `[피 고 인]`** 로 렌더한다(안쪽 공백은 그대로, 괄호만 교체). 본문 안에 나오는 `【…】`/`〖…〗` 줄도 같은 규칙. 데이터(cases.json)는 이미 `[ ]` 로 바뀌어 들어오지만, 렌더 쪽에서도 `【`→`[`, `】`→`]` 로 정규화해 두 경우 모두 처리한다.
- 앞으로 UI 어디에서도 `【 】` 를 쓰지 않는다.

## 2. 휘장 — 기본값은 조금 더 진하게, 설정에서 조절
- 휘장 밝기를 CSS 변수로: `.court-ic{filter:grayscale(1) brightness(var(--emblem-b,1.15)) contrast(.9);opacity:var(--emblem-o,.9)}` (다크 모드는 brightness 를 `calc(var(--emblem-b,1.15) + .6)` 정도).
- 설정 패널에 **"휘장 농도" 슬라이더**(연하게 ↔ 진하게, 5단계 또는 range 0–100). 값은 `lawbook:settings.emblem`(0–100, 기본 55)에 저장하고 `--emblem-b`, `--emblem-o` 로 환산(진할수록 brightness 낮고 opacity 높게). 현재 보이는 것보다 **기본값이 눈에 띄게 진해야** 한다(brightness ≈1.15, opacity ≈.9).

## 3. 탭 띠의 구분 라벨("표준판례", "최신판례") 장평 95%
- `.pagetabs .sec-l{display:inline-block;transform:scaleX(.95);transform-origin:left center}` (글자 크기는 그대로, 세로 중심 정렬 유지).

## 4. 정렬·장평·자간
- **양쪽 정렬 금지**: 템플릿 전체(판시사항·요지 항목, 전문, 법령 모듈 CSS 사본, 전문 부칙 등)에서 `text-align:justify` 를 모두 `left` 로. 복사해 둔 법령 모듈 CSS(`#laws-css`)도 고친다(`@media(min-width:700px)` 의 justify 규칙 삭제).
- **조문 내용(.lw-text)과 판결문 전문(.ft) 텍스트는 장평·자간 99%**: `letter-spacing:-.01em` 과 가로 99% 축소. 축소는 `transform:scaleX(.99);transform-origin:0 0;width:101.0101%` 를 **텍스트 블록 컨테이너**에 적용(시각 폭이 원래와 같도록). 전문 안 찾기·조문 바로가기·오른쪽 개요 클릭 시 스크롤 위치가 어긋나지 않는지 확인(getBoundingClientRect 기반이면 문제없음).
- 전문 본문 문단의 `text-indent` 제거(들여쓰기 없음). 번호 문단(가., 1), ① …)의 hanging indent 는 유지해도 좋다.

## 5. 오른쪽 개요(노션식) — 법령과 전문에 공통
- **주요법령**: 법령 목차(편·장·절·관 트리)를 왼쪽 열에서 빼서 **본문 오른쪽에 떠 있는 개요 패널**로 옮긴다(노션의 페이지 개요처럼: 본문 오른쪽 여백에 sticky, 얇은 글씨, 현재 보고 있는 장을 강조하는 scroll-spy). 왼쪽 열에는 **법령 목록만** 남긴다. 폭이 부족하면(본문 오른쪽에 220px 이상 확보되지 않으면) 개요는 본문 오른쪽 상단의 작은 "개요" 버튼으로 접었다 펼친다(팝오버). 모바일의 "목차" 버튼도 이 개요를 연다.
- **판결문/결정문 전문 탭**: 같은 방식의 오른쪽 개요를 시트 안에 둔다. 항목은 **"1." "2." … 수준의 소제목만**([이 유] 안의 `1. 사건의 개요와 쟁점`, `6. 대법관 …의 별개의견` 등; 가./나./(1) 은 넣지 않는다). 시트 폭이 넓을 때(≥ 980px, 전체 화면·넓게 늘렸을 때)는 본문 오른쪽에 상시 표시, 좁을 때는 탭 줄 오른쪽의 "개요" 버튼 팝오버. 클릭하면 시트 안에서 해당 소제목으로 스크롤, 현재 위치 강조(scroll-spy).
- 개요 패널 글꼴: 고딕 12.5–13px, 색 `--ink-2`, 현재 항목 `--accent-ink` 굵게, 왼쪽에 2px 보라 막대.

## 6. 시트 전체 화면 전환
- 시트 상단 바(닫기 옆)에 **전체 화면 토글**(아이콘: ⤢ / ⤡, 라벨 "전체 화면"/"시트로"). 켜면 시트가 뷰포트 전체를 덮고 본문 열은 가운데 정렬(최대 폭 880px) + 오른쪽 개요 상시 표시. 끄면 원래 시트 폭으로. 단축키 `f`. 상태는 `lawbook:settings.sheetFull` 에 저장(다음 판례도 같은 모드로 열림).

## 7. 시트 폭 조절
- 데스크톱(≥1024px) 시트의 **왼쪽 가장자리에 드래그 핸들**(6px, 호버 시 보라). 드래그로 480px ~ (뷰포트 − 120px) 사이에서 폭 조절, 더블클릭하면 기본 680px 로 복귀. 값은 `lawbook:settings.sheetWidth` 에 저장. 드래그 중 본문 텍스트 선택 방지(`user-select:none`), 포인터 이벤트(마우스·터치펜) 모두 지원.

## 8. 표준판례 목차 깊이 가변
- `DATA.toc[subject]` 트리는 **깊이 1~3단계**(대주제 › 중주제 › 소주제)가 올 수 있고, `case.tocPath` 길이도 1~3 이다. 목차 렌더(페이지의 차례, 슬라이드 패널 트리, 시트의 경로 표시, 빈 장 흐리기, 건수 집계)를 **재귀**로 바꿔 깊이에 상관없이 동작하게 한다. 현재 데이터(2단계)로 보이는 모습은 그대로여야 한다.

## 9. 그 외 유지·확인
- 이전 사양의 모든 항목 유지: 탭 순서(판시사항·요지 → 전문 → 참조조문·판례 → 메모), 정식 인용형식, 관련 판례의 조·항 규칙, 소제목은 "1." 수준만, 이어 읽기 없음, "헌재/전합" 금지, 라틴어 격언 1개, 섹션 제목 보라, 한 줄 머리 블록, 문단 간격.
- 검수: `python3 tools/sweep.py dist/design-d.html` 오류 0·가로 스크롤 0; 스크린샷으로 ① 탭 띠 라벨, ② 전문(괄호 `[ ]`, 들여쓰기 없음, 왼쪽 정렬, 오른쪽 개요), ③ 전체 화면 시트, ④ 시트 폭 드래그 후 모습, ⑤ 주요법령(왼쪽 법령 목록 + 오른쪽 개요 + scroll-spy), ⑥ 설정 패널의 휘장 슬라이더와 진해진 휘장, ⑦ 모바일(개요 버튼·전체 화면). 스크린샷을 Read 로 열어 확인한 뒤 보고.
- 작업 파일: `src/design-d.html` 만 수정. `tools/`, `data/`, `spec/` 은 건드리지 않는다(같은 시간에 다른 작업자가 수정 중). 빌드는 `python3 tools/build.py src/design-d.html`.

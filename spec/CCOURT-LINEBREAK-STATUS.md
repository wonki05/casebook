# 헌법재판소 주요결정 전문 줄바꿈 복구 (2026-11-07)

## 문제

`ccourt` 그룹 결정문 전문 가운데 korean-law API(`get_decision_text`, `retrieval.method == "korean-law:get_decision_text"`)로 수입한 **331건**은 API 가 결정문 본문의 줄바꿈을 모두 제거해 돌려주기 때문에 다음 상태였다.

- `【판시사항】`·`【결정요지】`·(`【참조조문】`·`【참조판례】`)·`【전문】` 섹션뿐이고, `【전문】` 한 덩어리 안에 `【당 사 자】…【주 문】…【이 유】…` 가 탭·공백으로만 이어짐(331건 모두 전문 줄바꿈 1개 이하).
- 판시사항·결정요지 항목도 "…여부(적극)2. …" 처럼 붙어 `build_data.split_items` 가 항목을 나누지 못함.
- 화면: 문단 구분 없음, `[주 문]` 전용 조판 미작동(섹션이 주문이 아니므로), 전문 "개요" 버튼이 빈 상태.

API 를 다시 불러도 같은 결과임을 2026-11-07 확인했다(상위 세션). 따라서 API 원문에서 줄바꿈을 추측해 넣지 않고 law.go.kr 페이지에서 다시 수집했다.

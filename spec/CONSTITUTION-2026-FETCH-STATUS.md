## 6. 방법과 한계

- 단원별 worktree 에서 `fetch_unit.py run --commit` 으로 병렬 수집, 통합 브랜치에 병합.
- 엑셀 쟁점·요지 대 공식 원문의 글자 단위 대조는 스크립트로 189건 전체를 훑어 의심 84건을 골라 검수 에이전트 84명이 읽고, 보고된 의심마다 반증자 2명이 원문을 다시 열었다(확정 26건 중 일부는 같은 사실의 중복). 스크립트 단계에서 차이가 없던 105건은 에이전트 검토 대상이 아니다.
- `fetch_unit.py audit` 의 '메타 불일치' 표시는 헌법재판소 인용문 형식(재판부가 앞에 오고 번호가 날짜 앞에 옴)을 읽지 못하는 한계에서 나온 거짓 경고라서 보고서(`spec/fetch-reports/constitution-*.json`)의 `flagged` 는 무시한다.
